# Result Schema

The test-result schema defines a normalized record for one assessment test. It requires an isolated-lab marker and records expected versus observed behavior, outcome, and limitations.

Use synthetic values in public examples. Never place production hostnames, IP addresses, certificate material, tokens, customer identifiers, or proprietary detection content in JSON artifacts.

The schema is a documentation aid. Validate it with a JSON Schema Draft 2020-12 validator in your local workflow before relying on it in automation.
