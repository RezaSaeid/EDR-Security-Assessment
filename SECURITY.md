# Security and Data Handling Policy

All assessment activity must be explicitly authorized and scoped. Prefer benign, reversible tests and synthetic data.

Never commit production telemetry, internal hostnames/IPs, certificates, tokens, customer identifiers, proprietary detection logic, or unredacted logs. Keep raw evidence private and publish sanitized summaries only.

Do not use public issues to disclose unpatched vulnerabilities in a vendor product. Follow the vendor's security reporting and coordination process.
